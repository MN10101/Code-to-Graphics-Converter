
# Code-to-Graphics Converter

This application visualizes various algorithms and fractals using a graphical interface built with WPF (Windows Presentation Foundation) in C#. It allows users to explore sorting algorithms and fractal generation in a visual and interactive manner.

## Features

- **Sorting Algorithms Visualizations**:
  - Bubble Sort
  - Quick Sort
  - Merge Sort
  - Heap Sort
- **Fractal Visualizations**:
  - Mandelbrot Set
  - Julia Set
- **Interactive Speed Control** for algorithms via a slider.

## Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/MN10101/Code-to-Graphics-Converter
   ```

2. Open the solution in Visual Studio (or your preferred C# IDE).

3. Build and run the project.

## Usage

- Press the buttons on the left panel to visualize the corresponding sorting algorithms or fractals.
- Use the "Speed Control" slider to adjust the speed of algorithm visualizations.

## Requirements

- .NET 5 or higher
- Visual Studio (or any C# compatible IDE)
